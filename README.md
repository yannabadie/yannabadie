## Featured Open-Source Repositories

- [**`eu-us-opendata-mcp`**](https://github.com/yannabadie/eu-us-opendata-mcp) — Zero-dependency, zero-API-key Python stdio MCP server for 5 official EU & U.S. government & biomedical open-data APIs (SIRENE/RNE, EU TED v3, NIH ClinicalTrials v2, U.S. CMS NPI v2.1, EMBL-EBI Europe PMC & PubMed) (MIT).
- [**`official-opendata-mcp-n8n-templates`**](https://github.com/yannabadie/official-opendata-mcp-n8n-templates) — Free ready-to-import n8n workflows, Claude/Cursor `mcp.json`, and zero-dependency Python CLI for French SIRENE/BODACC, EU TED/BOAMP tenders, NIH ClinicalTrials.gov v2, U.S. CMS NPI & PubMed/Europe PMC (MIT).
- [**`facturx-france-2027`**](https://github.com/yannabadie/facturx-france-2027) — Zero-dependency Python CLI & GitHub Action for validating French 2026–2027 Factur-X PDF/A-3 & EN 16931 CII XML invoices (MIT).
- [**`Meta-YGN`**](https://github.com/yannabadie/Meta-YGN) — Safety runtime for AI coding agents (AST command blocking, auto-checkpoint, meltdown detection, adaptive guards).
- [**`nexus-swarm-os`**](https://github.com/yannabadie/nexus-swarm-os) — Multi-model collaborative orchestration platform with cross-model verification and built-in security.
- [**`mnemo`**](https://github.com/yannabadie/mnemo) — MCP workflow for versioned decision review and server-checked exports.
